## Не проверено в Power BI — обязательная приёмка перед рабочим применением

| Проверка | Ожидаемый результат |
|---|---|
| Импорт в копию существующего PBIX | Обновляется тот же визуал, привязки и настройки сохраняются |
| Цвет → fx → значение поля → DAX-мера | Разные работы получают разные цвета; пустой результат возвращает постоянный цвет |
| Сохранить, закрыть, открыть PBIX | Роли, цвета, режим штриховки, подписи и настройка fx восстановлены |
| Сброс карточки / всех настроек | Сброшены в том числе скрытые параметры; данные не переназначаются |
| Закладки, фильтрация другими визуалами, multi-select и clear | Сохраняется поведение старой версии, прогноз следует той же работе |
| Встроенная панель фильтров | Сохраняются раскрытые секции, фокус и прокрутка |
| Вехи и разные формы/расположение основных и дополнительных полос | Прогноз только на обычных основных работах, не на вычисленных группах |
| Узкий/низкий viewport, плотные данные и длинные названия | Нет значимых перекрытий и недоступных действий |
| Высокий контраст, клавиатура, screen reader | Проверить весь исходный визуал и новые сведения; полное соответствие WCAG не заявлено |
| 29 999 / 30 000 / 30 001 строк | Проверить фактическую выдачу хоста и сообщение о неполноте; лимит не является гарантией полноты |
| Performance Analyzer и многократные update/resize | Измерить запрос, преобразование и отрисовку; проверить память |
| Power BI Service и экспорт | Проверить отдельно от Desktop |

Визуал не сертифицирован и не опубликован. Имитация API не подтверждает работу реального диалога fx, вычисление DAX, сериализацию PBIX или поведения Service. Файл-пример DAX подготовлен, но не выполнялся в Power BI.

## Технические ограничения

Восстановлена сборочная основа, оригинальные TypeScript-исходники отсутствуют. Пакет создаётся официальным emitter, но не стандартным TS-конвейером `pbiviz package`. Исходный код лицензирования не менялся; исходная ссылка на отсутствующий `visual.js.LICENSE.txt` сохранена. В зависимостях инструментов npm при установке сообщил о 4 moderate уязвимостях; эти dev-зависимости не включаются в новый runtime-слой пакета, принудительное обновление транзитивных зависимостей не выполнялось.

Вердикт: **код, воспроизводимая сборка и локальный стенд проверены; пакет подготовлен для приёмки в копии Power BI-отчёта. Приёмка в Power BI не завершена.**
