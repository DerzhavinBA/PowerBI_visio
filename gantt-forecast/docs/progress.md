# Выполнение плана прогноза Гантта

Основание: утверждённый план пользователя от 30.10.2026.

1. Восстановление воспроизводимой сборки — выполнено; содержимое baseline побайтово совпадает с исходным пакетом.
2. Модель прогноза — выполнено; календарные даты, точное время, идентичность строк, цвет, диагностика.
3. Отрисовка и форматирование — выполнено; неизменный vendor, отдельные модули, API 5.1, fx descriptor, разделы настроек и дополнительные группы.
4. Пакет, локальная проверка, инструкция — выполнено; 23 автоматических теста, браузерный стенд, пример DAX.
5. Приёмка в Power BI — не выполнена: доступного запущенного хоста и копии отчёта нет. См. acceptance.md.

Решения и отклонения:
- Созданное нативное рабочее дерево недоступно для записи из sandbox. По fallback скилла изменения выполнены в отдельном каталоге исходного разрешённого workspace. Попытка убрать пустое дерево отклонена приложением как primary checkout; исходный проект и его пакет не менялись.
- Исходный JS сохранён как vendor; это не оригинальный TypeScript-проект. Упаковка через официальный PowerBICustomVisualsWebpackPlugin.generatePbiviz с восстановленным JS.
- API 5.1 capabilities не допускает dateTime в requiredTypes; тип нового поля проверяется по метаданным DataView с понятной диагностикой.
- В исходнике нет ручного фиксированного диапазона дат оси; сохранены существующие масштаб и прокрутка, добавлено обрезание по текущей шкале.
- Сохранены все старые role/object/property идентификаторы и дефолты. Русские имена членов динамических списков сохранены при переносе панели.
- Независимое ревью указало на сравнение времени внутри дня и TextInput placeholder; оба исправлены с RED/GREEN тестами. Полная типизация генерируемой панели выявила дополнительные ошибки формы дескрипторов, исправлено.
- Коммиты, push, публикация и изменение оригинального отчёта не выполнялись.

## Доработка 1.6.1.0

По запросу пользователя добавлены 5 видов линии прогноза и явное название настройки. Новые стили: diagonal/dashed/dotted, прежние striped/solid сохранены. Цвет и fx общие для всех стилей. 28 тестов прошли, оригинальный пакет не менялся.

## Доработка 1.6.2.0

Добавлены ручные размеры линии и маркера с автоматическими значениями по умолчанию. Цвет линии задаётся текстовой DAX-мерой через новую роль forecastColor либо fx; маркер следует цвету линии или использует собственный fx. 38 тестов прошли, независимое ревью без существенных замечаний. Power BI Desktop/Service не запускались. Повторный просмотр обновлённого HTML-стенда заблокирован ошибкой подключения браузерного инструмента.
