# Работа с Power BI

Для проектирования, разработки и проверки визуализаций Power BI используй локальный комплект [powerbi-visual-guide](powerbi-visual-guide/README.md). Оформление ТМХИ — по умолчанию, если пользователь не задал другое.

Выбирай и читай соответствующий скилл, затем только нужные связанные материалы:
- [Проектирование](powerbi-visual-guide/skills/powerbi-visual-design/SKILL.md).
- [Разработка .pbiviz](powerbi-visual-guide/skills/powerbi-pbiviz-development/SKILL.md).
- [Проверка визуала](powerbi-visual-guide/skills/powerbi-visual-review/SKILL.md).

Это локальные инструкции для этого рабочего каталога, не глобальная установка скиллов. Пользовательское задание имеет приоритет. Для задач вне Power BI комплект не применяется. Отличай анализ файлов от проверки в Power BI; не называй поведение проверенным без запуска. Исходные примеры PBIX/PBIVIZ сохраняй неизменными, доработки создавай отдельно.
