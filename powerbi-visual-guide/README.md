# Визуализации Power BI — рабочий комплект ТМХИ

Версия комплекта: 1.0. Дата исследования: 24.10.2026. Язык: русский. Основной путь разработки — собственные `.pbiviz`, профиль ТМХИ по умолчанию.

## С чего начинать

1. Заполнить [задание](templates/visual-brief.md) и [контракт данных](templates/data-contract.md).
2. Применить [скилл проектирования](skills/powerbi-visual-design/SKILL.md): выбрать график, состояния и взаимодействия.
3. Применить [скилл разработки](skills/powerbi-pbiviz-development/SKILL.md), если требуется код визуала.
4. Применить [скилл проверки](skills/powerbi-visual-review/SKILL.md) и заполнить [приёмку](templates/acceptance.md).

Скиллы ссылаются на общие стандарты. При переносе сохранять всю папку: копирование одного SKILL.md разорвёт ссылки. Корневой AGENTS.md подключает их к работе в этом каталоге; глобальная установка не выполнялась.

## Как трактовать правила

**Факт** — подтверждён конкретным полем пакета или фрагментом сборки. **Требование платформы** — применимо в указанной версии API и подкреплено источником. **Рабочее правило** — выбранная практика для будущей разработки. **Предложение** — улучшение, ещё не применённое к исходным работам. Исторический пример не становится универсальным требованием.

Power BI Desktop не был запущен при исследовании; доступное управление нативным UI в этой сессии отсутствовало. Проверки отображения, взаимодействий, скринридера и реальной скорости в хосте не проведены. Наличие функций в сборке не подтверждает качество их исполнения. Исходный DataModel не декодировался, корректность DAX и значений не оценивалась.

## Обновление комплекта

После новой работы добавлять только подтверждённые повторяемые выводы. При смене API перепроверять связанные статьи и совместимость. Не обновлять SDK автоматически ради номера версии. Изменение общего правила вносить в соответствующий стандарт; скиллы остаются короткими маршрутами.

В комплект входят два служебных скрипта Python 3 (без сторонних библиотек): [сбор доказательств](scripts/inspect_artifacts.py) читает два исходных архива и обновляет evidence и результаты контраста; [проверка](scripts/validate_bundle.py) проверяет комплект и хеши оригиналов. Повторный сбор evidence заменяет снимок исходных хешей, поэтому для контроля неизменности сначала запускать проверку. Данные evidence предназначены для локального использования: они содержат названия полей и структуру внутреннего отчёта.

Проверка из рабочего каталога PowerBI:

```powershell
python -B powerbi-visual-guide/scripts/validate_bundle.py
```
