# Профиль ТМХИ по умолчанию

Основа — [оригинальная тема](tmhi-original.json), извлечённая из PBIX без изменения значений. Она не заменялась в отчёте. Следующие правила применения и альтернативы — предложения для новых визуалов, а не утверждённый корпоративный брендбук.

В теме `label`, `callout`, `title`, `header` используют Calibri; title/header — #004F9E, callout — #5CC4F2. В кастомном визуале использовать Calibri с системным fallback (например, Segoe UI, sans-serif), проверяя размеры при замене шрифта. Пользовательские настройки и high contrast имеют приоритет над профилем.

## Палитра и контраст

Расчёт относительной яркости sRGB по WCAG: [все результаты](contrast-results.json), [скрипт](../scripts/inspect_artifacts.py). Фон таблицы — непрозрачный #FFFFFF. Контраст проверен только для указанных пар.

| Цвет | Назначение | Контраст с белым | Применение |
|---|---|---:|---|
| #004F9E | Основной синий | 8.04:1 | Заголовки, основной ряд, текст |
| #406BB2 | Вторичный синий | 5.30:1 | Второй ряд и текст |
| #758CC7 | Светлый синий | 3.32:1 | Графика; не обычный мелкий текст |
| #5CC4F2 | Акцент | 1.97:1 | Заливка с тёмным текстом и при необходимости тёмным контуром |
| #D23100 | bad в исходной теме | 5.02:1 | Негативный статус с подписью/символом |
| #E59719 | neutral в исходной теме | 2.39:1 | Заливка; для обычного текста предложен #8A4B00 (6.80:1) |
| #01CD0B | good в исходной теме | 2.16:1 | Заливка; для обычного текста предложен #176B34 (6.58:1) |
| #242424 | Предложенный основной текст | 15.52:1 | Подписи на белом; на #5CC4F2 — 7.86:1 |

Белый текст на голубом также имеет 1.97:1 и не подходит для обычных подписей. Исходный цвет callout требует проверки на фактическом фоне. Светлую полосу, важную для понимания, на белом отделять достаточным контуром либо выбирать более тёмный цвет.

Не назначать все цвета длинного `dataColors` подряд без контроля различимости. Для последовательной величины выбирать последовательную шкалу, для отклонений — шкалу с осмысленным центром. Статусы «хорошо/плохо» определяет бизнес-смысл: рост не всегда положителен.

Для компактного Гантта: основной текст тёмный, выбранная строка различима контуром/маркером; веха отличается формой; текущая дата — подписанная линия; план/факт различимы без цвета. Конкретные цвета план/факт назначаются при проектировании и фиксируются в легенде.

Исходная JSON-тема предназначена для Power BI. Этот профиль — правила для автора визуала; host theme не гарантирует, что кастомный визуал автоматически применит все свойства. Проверить это при интеграции. Полный контраст отчёта и его соответствие WCAG не подтверждены.
