# Проверка комплекта

Дата: 24.10.2026. Проверяется документация и локальные скиллы, а не работоспособность исходных визуалов в Power BI.

## Структура и воспроизводимость

Проверка выполняется [validate_bundle.py](../scripts/validate_bundle.py): обязательные документы, ровно три скилла, согласование name с папкой, description и используемое подмножество YAML, локальные Markdown-ссылки, JSON, хеши двух оригиналов, соответствие извлечённой темы оригиналу и воспроизводимость расчёта контраста.

В скиллах используется строгое подмножество YAML: name без кавычек и description как JSON-совместимая строка. Валидатор не предназначен для произвольного YAML. Внешние источники проверены отдельно во время исследования, не загружаются валидатором.

## Сценарные критерии

| Сценарий | Ожидаемый маршрут | Что считается правильным результатом |
|---|---|---|
| Доработка Гантта | development → анализ Гантта → SDK/качество → review | Учтены API 4.7, legacy-панель, GUID/роли, лимит выборки, лицензии; миграция настроек не обещана без теста |
| Новый график задержек | design → brief/контракт → chart-design/тема/доступность | Определены метрика задержки и её знак, null и агрегация, сортировка, длинные подписи, смысл цвета и действия |
| Аудит готовой сборки | review → идентификация → стандарты → приёмка | Отделены static/runtime; объявленные capabilities не выданы за тест; Power BI проверки помечены непроверенными |

Это проверка применимости инструкций, не реализация трёх графиков и не доказательство улучшения относительно агента без скилла.

## Выполненные проверки

- Валидатор завершился с кодом 0: 18 Markdown-файлов (включая корневой AGENTS.md), 3 скилла, 8 JSON-файлов. Локальные ссылки разрешаются, хеши оригиналов совпадают, значения темы совпадают с PBIX.
- Отрицательные пробы: неверный frontmatter, пустой description и ссылка на отсутствующий файл корректно обнаруживаются. Контроль формулы контраста: чёрный/белый = 21:1, одинаковые цвета = 1:1.
- Отдельный агент выполнил read-only сценарный обзор трёх скиллов и связанных правил. Для Гантта он вывел необходимость сохранить контракт и отдельно планировать миграцию 4.7 → современная панель; для нового графика — определить знак задержки, null, идентичности и читаемость; для аудита без Desktop — оставить runtime-проверки непроверенными. Существенных вводящих в заблуждение утверждений не выявил.
- Во время независимого чтения два файла ещё создавались: этот протокол и валидатор. Замечание об отсутствующих адресатах закрыто последующей полной проверкой ссылок.
- Неблокирующее замечание: стандарт доступности не является исчерпывающей матрицей всех критериев WCAG 2.2 AA. Это ограничение сохранено явно; для отдельного полного аудита соответствия потребуется такая матрица.

## Редакторская оценка скиллов

Самооценка по десяти измерениям review-skill; не метрика качества графиков и не тест автоматического выбора скилла моделью. Для трёх скиллов оценки одинаковы, поскольку структура и механизм проверки общие.

| Измерение | Оценка | Основание |
|---|---:|---|
| Frontmatter | 5/5 | Требуемые поля валидны, имя совпадает с каталогом |
| Description / триггеры | 4/5 | Явные задачи и исключения; автоматический выбор не измерялся |
| Краткость | 4/5 | Короткие маршруты; часть обязательных ограничений повторяется намеренно |
| Структура | 5/5 | Стандарты вынесены, прямые ссылки на нужные материалы |
| Ясность | 4/5 | Определены вход/выход и шаблоны; конкретные данные будущего проекта неизвестны |
| Свобода решений | 5/5 | ТМХИ и .pbiviz по умолчанию, выбор графика по задаче |
| Обработка ограничений | 4/5 | Отсутствие исходников и host разобрано; реальные сбои будущих проектов не испытаны |
| Постепенное чтение | 5/5 | Указано, когда нужен анализ Гантта, отчёта и SDK |
| Собственные исполняемые скрипты скилла | Н/П | Скиллы не содержат исполняемых команд; общие утилиты проверены отдельно |
| Полнота | 4/5 | Три сценария охвачены; host-проверки требуют отдельной среды |

Итого: 40/45 применимых баллов для каждого скилла. SKILL.md содержат меньше 500 строк и существенно меньше 5000 токенов каждый; оценки токенов приблизительные, точный токенизатор не применялся.

## Ограничения

Не проверены Desktop/Service, настоящий tab order, экранный диктор, поведение фильтров, экспорт и скорость. Процесс PBIDesktop при исследовании не найден. Ни один пункт приёмки визуала не отмечен пройденным по одному лишь анализу метаданных. Полный исходный проект, DAX-модель и лицензионные условия отсутствуют среди исследованных материалов.
