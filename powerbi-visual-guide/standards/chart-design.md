# Выбор графика и достоверность

Рабочие правила комплекта; общий принцип выделения важного и уменьшения шума согласуется с [S13](../sources.md). Выбор определяется аналитическим вопросом, а не наличием эффектной библиотеки.

| Вопрос | Базовый вариант | Что проверить |
|---|---|---|
| Какие проекты больше / хуже / выше? | Горизонтальные столбцы или точки | Единицы, направление ранжирования, длинные названия |
| Как меняется показатель? | Линия по времени | Равномерность времени, пропуски, период сравнения |
| Когда идут работы и где задержка? | Гантт | Начало/конец, план/факт, вехи, часовой пояс |
| Как соотносятся план и факт? | Две серии либо bullet chart | Одинаковый масштаб и смысл отклонения |
| Как распределены значения? | Гистограмма / box plot | Границы интервалов, объём наблюдений, выбросы |
| Связаны ли две величины? | Диаграмма рассеяния | Единицы, пропуски; корреляция не доказывает причину |
| Нужны точные значения и много атрибутов? | Таблица / матрица | Порядок столбцов, закрепление контекста, итоги |
| Каковы доли целого? | Составной столбец; круг только для малого числа легко различимых долей | Общий знаменатель, 100%, отрицательные значения |

Перед кастомной разработкой проверить штатный визуал. Deneb подходит для декларативной нестандартной композиции, HTML/SVG — для специально согласованных сценариев; ограничения взаимодействий, экспорта и доступности проверять отдельно. Основной путь этого комплекта — `.pbiviz`, альтернативы не навязываются.

## Правила представления

- У столбцов, где значение кодируется длиной, нулевая база по умолчанию. Если выбран другой способ сравнения, явно обозначить диапазон; не маскировать усечение. Для линий допустим осмысленный ненулевой диапазон с читаемой шкалой.
- Не использовать 3D и площадь/радиус вместо длины без необходимости. Размер пузыря должен соответствовать площади, если площадь кодирует значение.
- Не соединять отсутствующие наблюдения как фактические значения. Отличать 0, неизвестно и неприменимо. Не подменять ошибки данных «нулевым прогрессом».
- Указывать единицы, валюту, период, агрегацию и знаменатель процентов. Не суммировать проценты и средние без определения их веса.
- Сортировать по смыслу: время по возрастанию, этапы по бизнес-порядку, рейтинг по метрике. При равенстве использовать устойчивый ключ.
- Категория должна сохранять цвет после фильтрации. Статус и принадлежность к проекту — разные кодировки; не переиспользовать один цвет с разным смыслом в одном контексте.
- Итог по видимым строкам и итог по всему набору обозначать отдельно. Top N показывать с явным ограничением и понятным «прочее», если оно рассчитано корректно.

## Гантт ТМХИ

Различать интервал работы, точечную веху, текущую дату и целевой срок формой или линией плюс подписью. Окончание раньше начала — ошибка данных, а не автоматически переставляемые даты. Одинаковые даты могут быть вехой только по контракту. Фиксировать, включается ли день окончания, используются ли рабочие дни и какой календарь задаёт «сегодня». Смена масштаба не должна менять исходные даты.

Если плотность требует скрыть часть подписей, сохранять доступ к полному названию через фокус/подсказку и осмысленный порядок строк. Нельзя улучшать внешний вид путём незаметного исключения работ.
